Import from old Weststar One

How importing works

The import runs on the server from the command line, so the old database password and encryption keys never pass through a browser. The old keys are read from the server's .env file.

# On the server, in the Weststar ONE folder (old keys go in .env as OLD_APP_KEY / OLD_ENCRYPTION_KEY)
# 1) Practice run — shows counts, saves nothing
./deploy/import-old.sh /path/to/old-dump.sql.gz /path/to/old/uploads --dry-run

# 2) Real import — safe to repeat
./deploy/import-old.sh /path/to/old-dump.sql.gz /path/to/old/uploads

Ticket, invoice and quote numbers stay the same. Old passwords and two-factor keep working. Re-running only adds and updates records that haven't been changed here since the last import, so nothing you change in the new app is overwritten.
