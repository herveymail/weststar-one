Stripe setup guide

{% if stripe.has_sk %}{% if stripe.mode == 'live' %}Live mode{% else %}Test mode{% endif %}{% else %}Not connected{% endif %}

Stripe takes the card and bank (ACH) payments for invoices and AutoPay. Clients type their card or bank details on Stripe's own page, so they never touch this server. About 15 minutes, start to finish.

{% if stripe.check %}
{% if stripe.check.ok %}Connected to {{ stripe.check.name|default:stripe.check.account }} ({{ stripe.check.mode }} mode) · Payments {% if stripe.check.charges %}on ✓{% else %}not on yet ✗{% endif %} · Payouts {% if stripe.check.payouts %}on ✓{% else %}not on yet ✗{% endif %}{% endif %} {% for p in stripe.check.problems %}

  1. 1
    Open a Stripe account

    Sign up or sign in at dashboard.stripe.com. To take real payments, finish Activate payments: business details, EIN, the owner's details, and the bank account payouts go to. Stripe starts you in a test sandbox, which is fine for trying things first.

  2. 2
    Choose how clients can pay

    In Stripe go to Settings › Payments › Payment methods. Leave Cards on. Turn on ACH Direct Debit if clients should be able to pay from a bank account (lower fees; it takes 3–5 business days to clear, and the invoice shows “Processing” until then). The payment page only offers what's switched on here.

  3. {% if stripe.keys_ok %}✓{% else %}3{% endif %}
    Copy the API keys into the boxes above

    In Stripe go to Developers › API keys (dashboard.stripe.com/apikeys). Copy the Publishable key (starts pk_) and click Reveal on the Secret key (starts sk_), paste both above and click Save changes. Both keys must come from the same mode: pk_test_ with sk_test_, or pk_live_ with sk_live_.

  4. {% if stripe.has_wh and stripe.last_event and not stripe.webhook_error %}✓{% else %}4{% endif %}
    Connect the webhook

    The webhook is how Stripe tells Weststar ONE that a bank payment cleared, a payment bounced, or a refund went through. Without it, card payments still record, but ACH payments stay “Processing” and refunds don't show.

    {% if can_manage and stripe.has_sk %}
    {% csrf_token %} Creates it in Stripe with the right address and events and saves the signing secret here. Run it again after switching from test to live keys.
    {% endif %}
    Or do it by hand in Stripe
    1. Open Developers › Webhooks (dashboard.stripe.com/webhooks) and click Create an event destination (older dashboards: Add endpoint).
    2. Pick Your account, and for the payload choose Snapshot — not Thin. Leave the API version as it is.
    3. Select these {{ stripe.events|length }} events:
      {% for e in stripe.events %}{{ e }}{% endfor %}
    4. Click Continue, choose Webhook endpoint, and paste this as the Endpoint URL:
      {{ webhook_url }}
    5. Save it, then on the webhook's page click Reveal next to Signing secret (starts whsec_), paste it into “Stripe webhook signing secret” above and click Save changes.

  5. {% if stripe.paid_online %}✓{% else %}5{% endif %}
    Try a test payment

    With test keys saved, sign in to the client portal as a contact who can see billing (for example a test client with your own email), open an unpaid invoice and click Pay … now. On Stripe's page use the test card 4242 4242 4242 4242, any future expiry date, any CVC and ZIP. You land back on the invoice, it shows Paid, and step 4 shows a message from Stripe. Test payments never move real money; delete the test payment from the invoice afterwards.

  6. {% if stripe.mode == 'live' and stripe.has_wh %}✓{% else %}6{% endif %}
    Go live

    In Stripe, switch off the sandbox / test mode, copy the live keys (pk_live_, sk_live_) into the boxes above and save, then click Set up the webhook for me again. Live mode has its own webhook and signing secret, so the test one won't work. Then click Check connection: Payments and Payouts should both say on.

  7. {% if stripe.autopay_on %}✓{% else %}7{% endif %}
    Turn on AutoPay (optional)

    Tick AutoPay is on above and choose when to charge. Clients join AutoPay by ticking “Save this card or bank account for AutoPay” when they pay, from the client portal (Invoices › Set up AutoPay), or from a setup link you email from the client's Invoices tab. If a charge fails it's tried again after the number of days set above, and the client is emailed.

Stripe's fees come out of each payment before it reaches your bank. The secret key and webhook secret are stored encrypted here and never shown again; to change them, paste new ones.
